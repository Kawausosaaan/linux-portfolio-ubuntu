# DNSキャッシュの動作検証

## 1. 検証目的

UbuntuのDNSキャッシュが名前解決の応答時間に与える影響を確認する。

## 2. 検証環境

| 項目 | 内容 |
|---|---|
| 検証日 | 2026年11月1日 |
| ホストOS | Windows 11 |
| ゲストOS | Ubuntu 24.04.2 LTS |
| 仮想化ソフト | Oracle VirtualBox |
| ネットワーク | NAT |
| 検証対象 | example.com |

## 3. 検証方法

DNSキャッシュの統計情報を確認した後、同じドメインに対して名前解決を繰り返し実行する。

### 使用コマンド

DNSキャッシュの統計情報を表示する。

```bash
sudo resolvectl statistics
```

ドメインの名前解決を実行する。

```bash
resolvectl query example.com
```

## 4. 検証結果

### DNSキャッシュ統計

| 項目 | 初期状態 | 初回問い合わせ後 | 再問い合わせ後 |
|---|---:|---:|---:|
| Total Transactions | 4 | 6 | 未記録 |
| Cache Size | 0 | 2 | 2 |
| Cache Hits | 0 | 0 | 2 |
| Cache Misses | 4 | 6 | 6 |

### 応答時間

| 条件 | 応答時間 |
|---|---:|
| 初回問い合わせ | 123.0 ms |
| 再問い合わせ | 1.1 ms |

再問い合わせでは、初回と比較して約112倍高速な応答が確認できた。

## 5. 考察

再問い合わせ後、Cache Hitsが0から2に増加した一方、Cache Missesは6のままだった。

この結果から、再問い合わせではDNSキャッシュが利用されたことを確認できた。

また、応答時間が123.0msから1.1msに短縮されたことから、キャッシュの利用が名前解決の高速化に寄与したと考えられる。

ただし、応答時間はネットワーク状況などにも左右されるため、今回の測定値が常に再現されるとは限らない。
