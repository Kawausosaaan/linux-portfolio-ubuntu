# Ubuntuログイン障害・パスワード復旧

## 1. 概要

VirtualBox上で稼働するUbuntuにログインできない問題が発生したため、パスワードの復旧を実施した。

本レポートでは、発生した問題、対応内容、復旧結果を記録する。

## 2. 検証環境

| 項目 | 内容 |
|---|---|
| ホストOS | Windows 11 |
| 仮想化ソフト | Oracle VirtualBox |
| ゲストOS | Ubuntu |
| ネットワーク | NAT |

## 3. 発生した問題

### 現象

Ubuntuへのログインができなくなり、通常の操作を開始できない状態となった。

### 影響

- Ubuntuへのログイン不可
- Linuxコマンドによる通常操作が実施できない
- サーバー学習作業が中断

## 4. 障害対応

### 対応内容

ログインできない状態から復旧するため、Ubuntuのパスワード復旧を実施した。

### 対応手順

具体的な復旧手順・使用コマンドは未記録のため、今後再現検証を行い追記する。

## 5. 復旧結果

パスワード復旧後、Ubuntuへのログインが可能となった。

その後、Linuxの基本操作やDNSの学習を継続できる状態になった。

## 6. 学んだこと

- Linux環境ではログイン障害によって管理作業が停止する場合がある
- ログイン障害の復旧には、適切な権限と復旧手段が必要になる
- 復旧結果だけでなく、原因・対応手順・確認結果を記録することが重要

- パスワード復旧手順の再現検証

- 復旧後のログイン確認手順の整理
