# 01. Linux基本操作（Ubuntu）

## 1. 学習目的

Ubuntu Server環境を使用して、サーバーエンジニアに必要なLinuxの基本操作を習得する。

特に、以下の内容を理解することを目標とする。

- Linuxの基本的な操作方法
- 管理者権限（sudo）の仕組み
- サーバーのシャットダウンと再起動
- 仮想マシンの基本的な管理

## 2. 学習環境

| 項目 | 内容 |
|---|---|
| ホストOS | Windows 11 |
| 仮想化ソフト | Oracle VirtualBox |
| ゲストOS | Ubuntu |
| ネットワーク方式 | NAT |

## 3. 学習内容

### 3.1 Ubuntuへのログイン

VirtualBox上に構築したUbuntu環境へログインし、Linuxの操作を実施した。

ログインできない問題が発生した際には、パスワードの復旧についても学習した。

### 3.2 管理者権限（sudo）

Linuxでは、システムの設定変更などに管理者権限が必要となる。

```bash
sudo <command>
```

**学んだこと**

- `sudo` は、許可されたユーザーが別のユーザー（通常はroot）の権限でコマンドを実行する仕組み
- 一般ユーザーと管理者では実行できる操作が異なる
- 管理者権限は必要な操作に限定して使用することが重要

### 3.3 シャットダウン

```bash
sudo shutdown -h now
```

**コマンドの意味**

| 要素 | 意味 |
|---|---|
| sudo | 管理者権限で実行 |
| shutdown | システムの終了処理 |
| -h | システムを停止 |
| now | 直ちに実行 |

### 3.4 再起動

```bash
sudo reboot
```

システムを再起動するためのコマンド。

設定変更やトラブル対応などで再起動が必要になる場合がある。

### 3.5 VirtualBoxの仮想マシン管理

VirtualBoxにおける以下の操作の違いを学習した。

| 操作 | 説明 |
|---|---|
| 状態保存 | 仮想マシンの実行状態を保存する |
| ACPIシャットダウン | ゲストOSに正常終了を要求する |
| 電源オフ | 仮想マシンの電源を強制的に切る |

通常は、ゲストOSから正常にシャットダウンする方法が望ましい。

## 4. 発生した問題と対応

### Ubuntuにログインできない

**現象**

Ubuntuへのログインができなくなった。

**対応**

パスワードの復旧を行い、ログインできる状態に戻した。

**学んだこと**

- ログイン障害が発生した場合は、原因を切り分ける必要がある
- パスワード復旧などの管理操作について理解することが重要
